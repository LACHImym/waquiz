# はじめての Apps Script（先生用のやさしい手順）

プログラムの知識はいりません。**画面に出てくる言葉のとおりにクリックとコピペをするだけ**です。
全体で 20〜30 分。途中でやめても、続きからできます。

---

## そもそも Apps Script って何？

Google のスプレッドシートに付いている「自動でやってくれる係」です。
スプレッドシートの中に「係の説明書（今回は `class-summary.gs` というファイル）」を置いておくと、
Google のコンピュータが決まった時間にそれを読んで、集計とページ作りをしてくれます。
先生のパソコンを付けっぱなしにする必要はありません。

今回の係がやること：
- 毎週月曜の朝、フォームの回答を集計して「各回の感想ページ」を作る
- 毎日朝、メインページの「授業から 1 週間たった回」のグレーを外す
- @g.neec.ac.jp でログインした人にだけページを見せる

---

## 用意するもの

| もの | どこにあるか |
|---|---|
| 学校の Google アカウント（@g.neec.ac.jp） | いつものログイン |
| 成績表スプレッドシート「2026前期デザイン史成績表」 | 個人の Google ドライブ |
| `class-summary.gs` というファイル | チャットでお送りしたもの。またはこのフォルダの `dist/class-summary.gs` |

---

## 手順

### 1. 成績表を学校アカウントに見せる（2 分）

1. 個人アカウント（gmail）で「2026前期デザイン史成績表」を開く
2. 右上の **共有** → 学校のメールアドレス（〜@g.neec.ac.jp）を入れる
3. 権限は **編集者** にする（係を置くために必要です）→ **送信**

### 2. 学校アカウントで成績表を開き、係の部屋を開く（1 分）

1. ブラウザで学校アカウントに切り替える（右上の丸いアイコン → 学校アカウント）
2. 「共有アイテム」から「2026前期デザイン史成績表」を開く
3. 上のメニュー **拡張機能** → **Apps Script** をクリック
4. 新しいタブで、左に「コード.gs」、真ん中に `function myFunction() {}` と書かれた画面が開く
   → これが「係の部屋」です

### 3. 説明書を貼り付ける（3 分）

1. `class-summary.gs` をメモ帳などで開き、**全部選択（Ctrl+A / ⌘A）→ コピー**
2. Apps Script の真ん中の欄をクリックし、**全部選択 → 貼り付け**
   （最初からあった `function myFunction() {}` は消えて OK）
3. 上の **保存アイコン（フロッピー）** を押す。または Ctrl+S / ⌘S
4. 左上の「無題のプロジェクト」をクリックして「デザイン史まとめ」など好きな名前に変える

> 画面が赤くならなければ成功です。もし赤い波線が大量に出たら、貼り付けが途中で切れています。もう一度 1〜3 を。

### 4. 「設定シートを作る」を実行して、許可を出す（3 分）

1. 上のツールバーに **▷ 実行** と **デバッグ** があり、その右に **myFunction** のような関数名の欄がある
2. その欄をクリックし、一覧から **createConfigSheets** を選ぶ
3. **▷ 実行** を押す
4. 「承認が必要です」と出る → **権限を確認**
5. 学校アカウントを選ぶ
6. 「このアプリは Google で確認していません」という**怖い画面**が出ます。
   これは「先生が自分で置いた係」なので出るだけで、正常です。
   左下の小さい **詳細** → 一番下の **（プロジェクト名）（安全ではないページ）に移動** をクリック
7. 「〜へのアクセスをリクエストしています」→ **許可**
8. 画面下の「実行ログ」に `設定シートを用意しました` と出れば成功

スプレッドシートに戻ると、下に **まとめ_回設定 / まとめ_分類辞書 / まとめ_タイプ辞書** の 3 つのシートが増えています。

### 5. 設定シートに授業日などを書く（5 分〜）

**まとめ_回設定** シートを開きます。

| 行 | 書くこと |
|---|---|
| 科目名 | デザイン史 |
| 学期 | 2026年度 前期 |
| 全回数 | 15 |
| 概要：科目の目的 | シラバスの文をそのまま |
| 概要：科目の概要 | 同上 |
| 回 1〜15 の行 | **授業日**（例 2026/4/15）、タイトル、授業概要URL（lachiart.com/designhistory/hi01/ など）、work1〜4 の設問文、観察 |

- **授業日がいちばん大事**です。この日から 7 日後にメインページのリンクが開きます。
- 休講や夏休みは、次の授業の日をそのまま次の回に書くだけです。
- 設問文と観察は空でも動きます。あとから足せます。
- デザイン史 2026 のタイトル・URL・第12回の分類辞書は、お送りした `designhistory-2026.config.json` に入っています。転記してください。

### 6. 「集計する」を実行（1 分）

1. Apps Script のタブに戻り、関数名の欄で **weeklySnapshot** を選んで **▷ 実行**
2. 実行ログに `スナップショット保存: …（14回 / 1247件）` のように出れば成功
   （Google ドライブに `まとめ_snapshot_デザイン史.json` というファイルができます。消さないでください）

### 7. ウェブとして公開する（3 分）

1. 右上の青い **デプロイ** → **新しいデプロイ**
2. 左上の **歯車** → **ウェブアプリ**
3. 次のように選ぶ
   - 説明：何でも（例「感想ページ」）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**g.neec.ac.jp のユーザーのみ**
4. **デプロイ** → 「ウェブアプリ URL」が出るので **コピー**
5. 左の **歯車（プロジェクトの設定）** → 下の方の **スクリプト プロパティ** → **スクリプト プロパティを追加**
   - プロパティ：`WEBAPP_URL`　値：さっきコピーした URL → **スクリプト プロパティを保存**
6. コピーした URL をブラウザで開く → メインページが出て、各回のボタンから感想ページに行ければ完成

> 学生には、この URL を伝えるだけで OK です。学校アカウントでログインしていないと開けません。

### 8. 自動化のスイッチを入れる（1 分）

1. 関数名の欄で **installTriggers** を選んで **▷ 実行**
2. 実行ログに `トリガー登録: …` と出れば完了

これで、毎週月曜の朝に集計、毎日朝にメインページの公開判定が自動で動きます。

## （あとでやればいい）lachiart.com にメインページを置く

メインページをウェブアプリの URL ではなく lachiart.com に置きたいときだけ行います。

1. WordPress で固定ページを 1 つ作る（本文は空）。編集画面の URL に `post=1234` とある数字を控える
2. WordPress の **ユーザー → プロフィール → アプリケーションパスワード** で「まとめ」など名前を付けて **新しいアプリケーションパスワードを追加**。表示された英数字（4 文字×6 組）を控える。この画面を閉じると二度と見られません
3. Apps Script の **スクリプト プロパティ** に 4 つ追加

| プロパティ | 値 |
|---|---|
| WP_URL | https://lachiart.com |
| WP_USER | WordPress のユーザー名 |
| WP_APP_PASSWORD | 2 で控えた英数字 |
| WP_PAGE_ID | 1 で控えた数字 |

4. 関数 **dailyPublish** を実行 → 固定ページの本文にメインページが入る
5. もう一度 **installTriggers** を実行（毎日の WordPress 更新が追加されます）

---

## 関数の名前と意味（関数名の欄で選ぶもの）

| 選ぶ名前 | やること | いつ使う |
|---|---|---|
| createConfigSheets | 設定シートを作る | 最初の 1 回 |
| weeklySnapshot | 今の回答で集計し直す | 最初の 1 回。あとは月曜に自動 |
| installTriggers | 自動化のスイッチを入れる | 最初の 1 回 |
| updateNow | 集計してメインページも更新 | 今すぐ反映したいとき |
| dailyPublish | メインページを WordPress に送る | WordPress を使うとき |
| saveHtmlToDrive | 全ページを Drive に HTML で保存 | 確認したいとき |
| removeTriggers | 自動化を止める | 学期が終わったとき |

## つまずいたら

- **「承認が必要です」が何度も出る** … 正常です。最初の 1 回だけ「詳細 → 移動 → 許可」を通せばあとは出ません。
- **「g.neec.ac.jp のユーザーのみ」が選べない** … 個人アカウントで Apps Script を開いています。手順 2 で学校アカウントに切り替えてから開き直してください。
- **URL を開くと「このページは学校のアカウント専用です」** … ブラウザが個人アカウントになっています。「アカウントを切り替える」から学校アカウントへ。
- **メインページに回が出ない／番号がずれる** … まとめ_回設定の「授業日」を確認。授業日の当日〜6 日後に回答が始まっているシートがその回になります。
- **コードを直したい・新しい版に入れ替えたい** … 手順 3 で貼り直して保存 → **デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ**。URL は変わりません。
- **実行ログに赤い文字** … その文をそのままチャットに貼ってください。
