## 3. できあがったもの

### 仕組み（Apps Script）

```
毎週月曜 6 時台  weeklySnapshot  フォーム回答 → 集計 → Drive にスナップショット JSON を保存
毎日   7 時台  dailyPublish    スナップショット → 今日の日付で公開判定 → メインページを WordPress に流し込み
閲覧のたび       doGet           スナップショット → 各回ページ・全体ページを描画（公開日前の回は中身を出さない）
```

- 氏名・学籍番号・メール・IP は **読み込み時点で捨てる**。文中の学籍番号・メール・電話番号・URL らしき文字列も伏せ字。
- 回とフォーム回答シートの対応は「授業日の当日〜6 日後に最初の回答があるシート」。授業日未記入なら並び順。
- 感想タイプ（知らなかった／腑に落ちた／複雑な気持ち／活かしたい／難しかった／楽しかった）はキーワード辞書で機械分類。辞書はシートで編集可。
- ワーク回答の分布は「まとめ_分類辞書」に書いた回だけカテゴリ集計、無ければ語の頻度。
- 「学生たちの声」は 55 字前後で上位語を含む文を自動選択、似た文は 1 つに絞る。
- 「観察」だけは人が書く欄（回設定シート）。

### ページ

| ページ | 置き場所 | 閲覧 |
|---|---|---|
| メイン（科目の目的・概要 ＋ 全15回：授業概要／授業感想ボタン） | lachiart.com 固定ページ（WordPress REST API で自動更新）またはウェブアプリ URL | 誰でも |
| 各回の感想ページ（観察／work1〜4 の分布と声／自由記述のタイプと語／タイプ別の声／質問） | Apps Script ウェブアプリ `?round=N` | 学校アカウント（または public） |
| 全回を通した傾向（タイプ割合・頻出語・回ごとの帯） | 同 `?page=overall` | 同上 |

### 設定シート（成績表の中に自動作成）

- **まとめ_回設定**：科目名／学期／全回数／概要（目的・概要）／回ごとに **授業日**・タイトル・授業概要URL・work1〜4 の設問・観察
- **まとめ_分類辞書**：回・work・カテゴリ・キーワード
- **まとめ_タイプ辞書**：感想タイプの表示名・説明・キーワード

## 4. 起きた問題と対処

| 日付 | 症状 | 原因 | 対処 |
|---|---|---|---|
| 9/15 | 「デプロイしたのにシートが増えない」 | デプロイは公開操作で、シートを作るのは `createConfigSheets` の実行 | 手順書に明記。成績表と未接続のときは日本語で原因と直し方を表示するよう変更（`SPREADSHEET_ID` をスクリプト プロパティでも指定可） |
| 9/16 | 「link-sso.neec.ac.jp で接続が拒否されました」（授業感想ボタン） | ウェブアプリ内リンクが Google の枠（iframe）の中で開き、学校 SSO が枠内表示を拒否 | `<base target="_top">` を入れてページ全体で開くよう修正。メインページに学生向けのログイン案内を自動表示 |
| 9/16 | 学生への導線が分かりづらい | 学校ログインが必要 | `ACCESS=public` ＋ デプロイ「全員」で誰でも閲覧可能に切り替え可能にした |

## 5. 現在の状態と、先生側の残作業

**先生側で行う設定**（手順書のとおり）
1. 学校アカウントで成績表をコピーし、その表から「拡張機能 → Apps Script」を開く
2. `dist/class-summary.gs`（最新版）を貼って保存
3. `createConfigSheets` を実行 → 設定シートに授業日などを記入（config.json から転記）
4. `weeklySnapshot` を実行
5. ウェブアプリとしてデプロイ（g.neec.ac.jp のみ、または全員）→ `WEBAPP_URL` をスクリプト プロパティに
6. `installTriggers` を実行
7. （任意）WordPress の固定ページとアプリケーションパスワードを設定して `dailyPublish`

**未着手・保留**
- 第 8〜11 回、13・14 回の work 設問文（シートに無いため「WORK1」表示のまま。回設定シートに書けば反映）
- 第 15 回はフォームなし → 「授業感想」ボタンは常にグレー
- デザイン研究1（2026後期）：開講後、同じ手順で別プロジェクトを作れば動く
- デザイン研究2：列構成（感想／work解答／質問）と Padlet 書き出しに合わせて `analyze.js` の列検出を広げる必要あり
- lachiart.com への設置（WordPress 側の固定ページとアプリケーションパスワードは先生の操作が必要）
